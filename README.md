## 登場人物

佐間良斗：主人公、1988年7月21日生まれ男性。生命の泉＝レーベンスボルン計画で出生し孤児院で育つ。中学卒業と同時に川口市内のアパートで一人暮らしを始めたが、隕石落下による校舎の半壊で分校のあるグンマーへの移住を強いられる。性格は皮肉屋で冷笑的だが、仲の良い友人には素直になり義理がたい。主人公だがあまり自分で活躍することは多くない。名前の由来はロシア語で飛行機という意味の「самолет」。

一色隼人：1988年7月7日生まれ男性。主人公と同じく孤児院で育つ。佐間良斗のクラスメートで友人。オタク趣味だが明るい性格。コンピューターは機械に強く結構頼れる人物。数学が得意。ハッキングもお手の物。名前の由来は一式戦闘機「隼」。

相田鈴：1988年6月3日生まれ女性。主人公と同じく孤児院で育つ。佐間良斗のクラスメートで友人。性格は朗らかで面倒見のいいお姉さん的な存在。名前の由来は操舵輪。

GT-RX86：2003年12月25日完成。AIを搭載したロボットで川口市立第一高等学校分校の数学教師。主人公たちの所属するクラス23組の担任。名前が複雑なので、ハチロク先生と呼ばれている。宇宙服のような見た目で胸にはタッチパネル式の操作盤が付いおり、操作入力、映像やグラフの表示が可能。また、空を飛ぶことも可能で、箱のような胴体の後ろに出っ張った部分を開き、そこからジェットエンジンと翼が展開される。データをロードすることで学習することが可能。例えば車の運転など。
動力源は原子力で、男のイチモツのような形をした原子炉が、冷却の必要性から、これまた男のイチモツがある場所に付いている。金玉のように丸い２つの玉で冷却水を冷却し、その玉の間に縦に長い圧力容器が配置され、中に核燃料棒が入っていて、冷却水で冷やされている。そのため臨界状態を迎えると股間がチェレンコフ放射する様子が見られる。

GT-RX85：GT-RX86と同じモデルのロボット。能力はGT-RX86と同じ。しかし、こちらは国語の教師で22組の担任。ハチゴー先生と呼ばれている。

田所浩蔵：1974 年8月10日生まれ男性。川口市立第一高等学校分校の体育教師。一度男子生徒へのセクハラで逮捕されたが、東条校長から直々に体育教師としてスカウトされた。

青木宇美：川口市立第一高等学校分校の保健体育担当の女性教師。20組担当。元は知名度のあまり高くないポルノ女優だったが、ポルノが青少年に間違った性の知識を与えているという調査報告があることをテレビで知り、今流星までの自分の行動に責任を感じ、教師として正しい性の知識を教える義務があると考え、教師を目指した。その結果、無事教員免許を取得し、一度都内の公立中学の保健体育を担当したが、ポルノ女優という経歴を隠していたため、その経歴が見つかり、経歴詐称として、懲戒解雇される。もはや教師としての道は絶望的と思われていたが。川口市立第一高等学校の採用面接で、ありのままの経歴を話し、保健体育教師として採用される。しかし、この採用は、グンマー動員を見越してのことだった。
矢部博士： 川口市立第一高等学校分校の養護教諭。東京帝国大学医学卒業。卒業後は医師免許を取得し、東京帝国大学付属病院で外科医として勤務するが、患者の不審死が相次いだため、警察が調査したところ、彼が実験のため、勝手に患者を解剖した結果だった。本人は殺すつもりはなく、本当に治療しようと試みたものだったが、彼自身の独自の手法やまだ最新の理論で安全性が確保されていない手法だったため、失敗することが多く、患者の死を厭わないものだった。故に警察に逮捕され懲役刑に処された。2003年の終わりに出所し、 川口市立第一高等学校の採用試験を受けたところ、養護教諭として採用される。今の所、人間を実験台にするつもりはない。

東条秀雄：川口市立第一高等学校の校長先生。口達者だかほとんどは口からでまかせ。無責任で自己利益優先。学校の生徒を帝国に売った張本人。

石原貫太：石原組警備部門責任者。指定暴力団石原組組長の三男。川口市立第一高校10組から24組のグンマー移住に伴い必要とされる護衛任務の責任者。

中島玲：1980年4月21日生まれ女性。東京帝国大学法学部卒業。川口市立第一高等学校分校の英語教師かつ裏の顔はグンマー解放戦線の参謀。しかし実際は、帝国陸軍特殊作戦部隊が、陸軍がグンマー自治区を軍事侵攻するための口実を作るために、グンマー解放戦線に忍びこませたスパイ。しかし、工藤凛に対する恋心は本物だった。名前の由来は中島飛行機と零式艦上戦闘機。

工藤凛：1978年5月11日生まれ女性。グンマー解放戦線のリーダー。法経大学経済学部経済学科卒業。大学2年生の時に、アメリカのポートランドにあるポートランド州立大学に1年間留学していた。その時に、欧米のリベラル的思想に染まる。両親が離婚していたため、大学卒業までは母親と2人で暮らしていた。母親からは「女は早く結婚して子供を産むのが一番幸せだからあなたもそうすべきよ。」とよく云われていて、それが気に食わず、「お母さんは時代遅れで古臭い日本の考えに蝕まれている。今の時代は女もバリバリ働く時代。私は大学卒業したら働く。」と反論していた。しかし、大学在学中に就職活動に失敗し、卒業後もしばらく無職でいた。そして、就職失敗の原因は日本の男女雇用機会が不平等だからだと思い込み、就職活動を諦めて、父親のグンマー解放戦線に参加。父親の死後は、リーダーとなりグンマー解放戦線を率いる。名前の由来は駆動輪。

工藤経：1951年8月15日生まれ男性。工藤凛の父親で初期のグンマー解放戦線リーダー。名前の由来は駆動系。

## 地理・世界情勢

第二次大戦で日本が負けなかった世界線。

大日本帝国は1944年にアメリカと停戦に持ち込み無条件降伏を免れる。その後帝国は、満州、チベット、モンゴル、東トルキスタン、南洋諸島、インドと共に大東亜連邦を形成した。

その後は史実と同じように、米ソ冷戦が始まるが、この世界では日米ソの三つ巴の冷戦となる。

史実から遅れて1951年にアメリカが世界初の原爆実験に成功し核保有国となる。1年遅れの1952年に帝国が世界で2番目の原爆実験に成功し、核保有国となる。その後1955年にソ連が原爆実験に成功し核保有国となる。

アメリカは西側諸国や中華民国といった自由主義陣営と手を組みNATOを形成。ソ連は東欧や中央アジアといった社会主義陣営でワルシャワ条約機構を形成。帝国は上記の大東亜共栄圏を形成し対立しあった。

しかし、1991年にソ連が崩壊し、2004年の現在は日米の2大超大国による冷戦構造となっている。

ソ連崩壊以降、アメリカはEU諸国やその他の西側陣営と共謀し、帝国に対して集中的に某略活動を繰り広げている。現に、帝国内で発生する様々な事件は、アメリカを中心と西側諸国に背景を持つものが多い。

## 物語序盤：
    -  グンマー解放戦線が大勢で学校の敷地前まで来てデモをおっ始める、シュプレヒコールをあげる。
      シュプレヒコールは以下の通り、
      「帝国臣民は出ていけ。」
      「帝国なんざクソ喰らえだ。」
      「天皇のケツの穴でも舐めてやがれ。」
      「ここはグンマー共和国だ。帝国なんかじゃねえ。」
    - 上記のシーンの後、解放戦線の一部の者が学校の敷地を僅かにまたいだため、学校を警備する石原組と殴り合いからの殺し合いに発展する。結果は石原組が勝つが、かなりの損害を被る。
    - 物理の授業が始まった。
    　先生は
    「最初だから面白い実験をしましょう。実験は校庭で行うので、皆さん校庭に出て下さい。」
    といい、皆が校庭に出ると、昨日捕まえた解放戦線の一人が縛り上げて吊るされていた。
    「頼む助けてくれ。もうあんた達には構わないから。もう郷に帰っておとなしくするから。頼むお願いだ。」
    と彼は、教師と生徒達を見るやいなや命乞いをした。
    ここで教師は、
    「では皆さん今日はモンキーハンティングの実験をして物理を親しみ易くしたいと思います。」
    - 数日後、今度は解放戦線がリーダーの工藤凛に引き連れられたやってくる。しかも、今回は教室の仲間で入ってきた。
      石原組はどうしたのか。おそらく負けたらしい。校庭に目をやると石原組の死体が転がっている。廊下にも目をやるとそこら辺にも転がっている。
      今は英語の時間だがお構いなしに俺達の教室に入ってきた。
      そしてリーダーがこう言った。
      「我々はグンマー解放戦線だ。そしてこの私がリーダーの工藤凛だ。この学校の責任者は誰だ。校長か。」
      なんとグンマー解放戦線のリーダーは女だった。そして英語教師の中島先生が答えた。
      「校長は川口の本校の校長室で高級オフィスチェアのアーロンチェアに座ってふんぞり返っているわ。残念ながらここには居ないの。」
      「じゃあ、誰が今この分校を取り締まっているんだ。」
      「それは私よ。何が言いたいの。」
      「だったら話が早い。我々は、貴様ら教師と生徒が直ちにここから立ち去ることを要求する。」
      「それは無理ね。彼ら生徒はここで勉強しないといけないもの。ここは進学校だから、今から3年後の大学受験に集中しないといけないの。わかったら出てって頂戴。」
      中島先生は肝っ玉の座った人だ。飛び道具はないとは言えバットや鉄の棒、バールのようなもので武装した解放戦線の連中に怯むことなく、おちょくった口調であしらった。
      しかし、解放戦線のリーダーといい中島先生といいグンマーは気の強い女が多い。流石はかかあ天下のグンマーだ。でも、彼女たちの出身は別にグンマーとは限らない。

## 物語終盤：
    - 佐間良斗：2004年の川口市立第一高等学校の入試結果から2005年度も本校では収容しきれないほどの大量の生徒を入学させることを知ったグンマー解放戦線の構成員がリーダーに問う。
      「本校がまだ再建されていないのに、これだけの生徒を入学させている。奴らは意図的に生徒をこちらに送って、実効支配を強化するつもりです。工藤さん、こ石原のまま指を食わていたら、奴らの思うままです。我々も手を打たねばなりません。この際、実力行使も」

      「凛ちゃん、もうやるしかないと思うわ。」
    - 中島玲玲が工藤凛を殺害する直前に、自分の正体を明かし、自分が帝国の任務のために解放戦線に送られて来ていたことを吐露する。そして、最後にすべてを教えた理由は、彼女が工藤凛を愛していたことは本当のことであり、愛している人だからこそ、例え自らの手で殺さざる負えなくとも、その前にすべての事実を教えて置きたかったと伝える。
      しかし、工藤凛は彼女のことを特別に愛していたわけではなく、ただ欧米のリベラル的な思想を体現するために彼女との同性愛的関係を演じていただけであったことを彼女に伝え、彼女に殺される。
